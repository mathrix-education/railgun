# OpenAPI

We use OpenAPI to write our documentation. Please refer to the [Official OpenAPI Specification](https://github.com/OAI/OpenAPI-Specification/blob/master/versions/3.0.1.md).

## Operation
When we are describing an Operation, we chose to organize its fields in this order. If the operation does not require
 one of them, just ignore it.

Fields order:

1. tags
2. operationId
3. summary
4. description
5. security
6. parameters
7. responses
